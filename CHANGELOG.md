# Changelog

## 0.1.0-alpha.1

- Added a modular public package entry point and CLI.
- Added QR and token session persistence.
- Added `LineClient`, `PublicBot` and `SelfBot` APIs.
- Added extended Talk, Call, LIFF, Square, Relation and OBS services.
- Added safe revision bootstrapping for SYNC4 listeners.
- Added configurable application profiles and request identity.
- Added phone registration with password derivation and manual human verification.
- Updated Apache Thrift and added dependency security checks.
